Sandbox Mode Concepts

Pick the visual language before we build the game layer.

These are standalone concept mocks for the more gamified live sandbox. Each one makes a different bet on what should dominate the screen: operations control, moving flow, tactical interventions, or container accumulation density.

All concepts are standalone HTML files.
They intentionally use different layout priorities.
Choose based on what you want users to notice fastest.

Option A: Control Tower

Closest to a real terminal command center. Central map, intervention deck on the left, KPIs and alerts on the right, and a plot strip below. Best if you want operational credibility first.

Most balanced Best for shared-resource logic Low ambiguity
Open Concept

Option B: Flow Theater

Big cinematic movement across the screen. The terminal is presented as a sequence of stages with animated flow streams. Best if you want causal motion and throughput to feel dramatic and intuitive.

Most visual Flow-first Strong presentation mode
Open Concept

Option C: Tactical Board

Leans into the intervention loop. The command choices feel more like a strategy board, with action cards, consequences, and mission-style priorities. Best if you want stronger sandbox-game energy.

Most gamified Intervention-first Great for disruption play
Open Concept

Option D: Yard Pressure

Built around accumulation. Queue and yard dots dominate the screen so users can see buildup physically, not just numerically. Best if container pile-up is the main visual metaphor you want to teach with.

Most dot-driven Best for congestion legibility Strong yard focus
Open Concept

If you want to rank them quickly: choose Control Tower for seriousness, Flow Theater for narrative clarity, Tactical Board for sandbox-game feel, or Yard Pressure if container accumulation should be the dominant visual language.
