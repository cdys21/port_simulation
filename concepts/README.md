# Sandbox Concept Mocks

These standalone HTML files are visual exploration only. They are not wired into the simulation engine.

Files:

- `index.html`: landing page with summaries
- `control-tower.html`: balanced, serious operations room
- `flow-theater.html`: cinematic flow-first direction
- `tactical-board.html`: most gamified disruption sandbox
- `yard-pressure.html`: strongest dot-density accumulation view

Open any of them directly in a browser, or start a simple local file server from the repo root:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000/concepts/`.
